# Sankofa

*Вернись и забери то, что оставил.* Санкофа — символ адинкра у народа акан в
Гане: птица, которая оборачивается назад и берёт яйцо со своей спины.

Sankofa — это дистрибутив Kubernetes, который помнит, и музей семи веков
чёрной культуры, который едет внутри него: от библиотек Тимбукту до звездолётов
Сан Ра. Каждая карточка короткая, удивительная и с источниками. Каждый факт
независимо проверяют два агента, и у каждого должно быть по два независимых
авторитетных источника.

English version: [README.md](README.md).

## Что получает кластер

| Механика | Что даёт | Откуда образ |
|---|---|---|
| **Griot**, память | Жизнь каждого объекта, в том числе после удаления: `sankofa tell deployment/web`, `kubectl get timelines`. Статус и значения секретов не хранятся, чтение памяти подчиняется RBAC. | Гриот, хранитель устной истории Западной Африки |
| **Sankofa fetch** | Вернуть объект таким, каким он был в любой момент: `sankofa fetch deployment/web --at 2h` | Птица Санкофа |
| **Kgotla** | Объекты с меткой `sankofa.kuberoot.dev/kgotla=protected` удаляются только после совета: высказались все названные голоса, вождь — последним. Имена берутся из аутентификации. | Кготла у тсвана |
| **Полиритм** | `H` в минутах CronJob (`H 3 * * *`): задания занимают свободные доли и не стартуют все разом. | Западноафриканские ансамбли в 12/8 |
| **Credits** | `sankofa credits pod/x` показывает объявленную родословную образа; вебхук предупреждает о образах, скрывающих базу, источник или лицензию, или отклоняет их. | «Hound Dog» сначала спела Big Mama Thornton |
| **Story** | `sankofa story deployment/web` рассказывает инцидент в трёх книгах (события, изменения, наследники) и показывает, где они расходятся. | «Хазарский словарь» Павича |
| **Pulse** | Сердцебиение кластера живым потоком; музей играет его полиритмом. | Зов и отклик |

## Что получает человек

- `sankofa dict` — бесконечный словарь в терминале в духе Павича. У ссылок
  значок книги, в которую они ведут (❝ голоса, ▤ архивы, ✶ наследники).
  Каждой установке достаётся мужской или женский экземпляр.
- `sankofa atlas` — карта мира шрифтом Брайля с таймлайном. Масштаб означает
  уровень обобщения: от пяти веков Атлантики до одного документа.
- `sankofa genre why|rdeps|audit hip-hop` — музыка как граф зависимостей.
- `sankofa quest` — настоящие дилеммы (правильного ответа нет: ты узнаёшь, что
  выбрал реальный человек и чего это стоило), квизы и прогулки по словарю.
- `sankofa wait -- <команда>` — удивительная строчка, пока идёт долгая команда.
- Веб-музей — спецпроект со скроллителлингом, атласом, таймлайном и всеми
  карточками. Любая ссылка из терминала открывается в той же точке.

## Установка аддонами

```bash
kubectl apply -f deploy/crds/
kubectl apply -f deploy/griot.yaml      # сначала подставить ссылку на образ
kubectl apply -f deploy/webhooks.yaml
go install ./cmd/sankofa                # или: kubectl sankofa
```

Музей: `web/` и `web/Dockerfile`, манифест `deploy/museum.yaml`. Публичный
вход для посетителей только на чтение: `deploy/visitor.yaml`.

## Содержание

Карточки лежат в `content/cards` ([формат](docs/card-format.md)), главы — в
`content/chapters`, квесты — в `content/quests`. `sankofa content lint
content/cards` проверяет источники, ссылки, координаты и длину.

## Тесты

```bash
go test ./...
hack/e2e/addons.sh      # на кластере: карточки, память, fetch, RBAC, Kgotla, полиритм, Credits, посетитель, музей
cd web && npm test && npm run e2e
```
